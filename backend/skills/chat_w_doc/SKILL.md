## Tool

`chat_w_doc_invoke` — вызов навыка работы с документами.

Параметры (в обёртке `data`):

- `thread_id` — идентификатор диалога (UUID)
- `history_messages` — история; последнее сообщение — текущий вопрос пользователя
- `message_id` — опционально
- `file_ids` — id файлов текущего сообщения (нужен хотя бы один файл в запросе или в истории чата)
- `intent` — что нужно сделать: `summarize` (краткое содержание) или `qa` (ответ на
  вопрос по тексту). Передавай всегда, когда знаешь: документ приложен без пояснений —
  `summarize`; спрашивают про конкретный пункт, сумму, срок — `qa`. Без параметра навык
  определяет сам по тексту запроса, и на неясной формулировке может выбрать иначе.

## Порядок

1. Убедись, что есть документ (`file_ids` или ранее загруженный файл в чате).
2. Вызови `chat_w_doc_invoke`.
3. Не переписывай ответ tool своими словами — ответ уже уходит стримом.
